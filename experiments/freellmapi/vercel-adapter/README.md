# FreeLLMAPI Vercel experimental adapter\n\nThis is a **stateless, text-only OpenAI-compatible Gemini gateway**, not the full upstream FreeLLMAPI server/dashboard. Upstream requires persistent SQLite and background workers, which are not portable to Vercel Functions as-is.\n\nRequired Vercel encrypted environment variables: `GEMINI_API_KEY` and `PROXY_ACCESS_TOKEN`. Do not commit either secret. Both must be present before requests are enabled. Endpoint: POST /api/v1/chat/completions. Authorization: Bearer <PROXY_ACCESS_TOKEN>. Only `gemini-2.5-flash` allowed; configure Gemini API billing disabled and monitor free quotas in Google AI Studio. No streaming, images, tool calls, persistent routing, or dashboard. No claims of zero charges unless provider account billing is disabled.\n
