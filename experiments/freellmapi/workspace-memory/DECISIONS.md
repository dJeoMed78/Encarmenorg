# Decisiones vigentes

1. GitHub será el registro persistente y versionado de contexto de trabajo de FreeLLMAPI.
2. El proveedor/modelo de IA es intercambiable; el historial pertenece al proyecto, no al proveedor.
3. El modo automático debe intentar el proveedor alternativo ante límites de cuota o fallos temporales.
4. Las conversaciones y resúmenes se separan por proyecto y sesión.
5. Guardar únicamente contenido necesario para continuidad; eliminar secretos y datos sensibles antes de persistir.
6. La rama experimental de FreeLLMAPI es el único destino autorizado para esta implementación.
7. Nunca tocar producción de ENCARMEN ni el proyecto principal IA para Todos.
8. No activar servicios de pago ni facturación sin autorización expresa.
